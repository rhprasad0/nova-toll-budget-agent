# Non-I-95 directional access

Four representative cases require a structured mismatch before pricing: the
Westpark-to-Scott cross-corridor request, direct I-66 and I-495 endpoint
mismatches, and the Greenway's Compass Creek exit-only ramp.

Run `uv run python eval/deterministic/non_i95_directional_access/deterministic_non_i95_directional_access.py --check` for the fixture check, or omit `--check` for live agent evidence.
