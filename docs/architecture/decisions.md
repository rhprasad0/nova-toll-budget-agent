# AgentCore deployment decisions

**Status:** private preview and public beta implemented in Terraform.

- **Private preview:** `preview.tollchat.ai` resolves to an execute-api interface endpoint. A private API Gateway custom domain and API resource policies both require that endpoint, whose security group accepts HTTPS only from the Tailscale router.
- **Invocation paths:** the private API Gateway and public CloudFront `/api/*` origin both stream through the same Node.js Lambda proxy. CloudFront signs requests to an IAM-protected Lambda URL through OAC, attaches WAF, and allows only config, chat, and reset operations. The proxy validates AgentCore SSE, exposes only tool label/status events plus the guarded final answer, and signs AgentCore calls with its dedicated role. The runtime policy still requires the AgentCore VPC endpoint (`aws:SourceVpce`).
- **Public beta:** `tollchat.ai` serves the open-beta interface from the private S3 origin. Terraform can remove the public API independently with `enable_public_chat=false`; the WAF default action is the immediate public-only switch.
- **Credentials:** `/nova-toll/openai_api_key` remains a SecureString in SSM Parameter Store. It is read at runtime by the dedicated AgentCore role and is never copied into Terraform state or an AgentCore credential provider.
- **Sessions:** the proxy creates a random 256-bit credential in a `Secure`, `HttpOnly`, `SameSite=Strict`, `__Host-` cookie and stores only its SHA-256 hash beside a server-generated `runtimeSessionId` in DynamoDB. Conditional updates enforce a 15-minute idle timeout, 60-minute absolute lifetime, reset revocation, and an expiring per-invocation lease so reset cannot race an authorized chat. DynamoDB TTL performs later cleanup only. A browser-native cross-tab lock permits one active chat tab, and each newly owning page rotates the backend session before enabling an empty transcript. Each runtime id receives a dedicated AgentCore microVM; AgentCore Memory and persistent chat storage are not enabled.
- **Availability:** two private subnets support interface endpoints and runtime. One NAT gateway is intentional for the private preview; add one per AZ before an availability SLO requires it.
- **Traces:** retain every invocation for 30 days using split AgentCore telemetry. Native spans redact message/system content; correlated application records contain sanitized prompts, responses, model messages, tools, and full Guardrail assessments. System-prompt text is excluded and represented only by its version.
- **Guardrail boundary:** because TollChat invokes OpenAI rather than a Bedrock model, it uses the standalone `ApplyGuardrail` API instead of Converse `guardrailConfig` or selective `guardContent` blocks. INPUT uses HIGH prompt-attack filtering; INPUT and OUTPUT use MEDIUM hate, violence, sexual, insults, and misconduct filtering. Both blocked paths return only “I can only help with Northern Virginia toll road estimates.” Production explicitly pins an approved numbered version, retains new candidates and prior versions, and promotes a candidate only after live evaluation. Terraform prevents automatic Guardrail identity replacement and rejects promotion until the approved version exists on the managed identity. It never sends a guardrail `trace` option; `outputScope=FULL` assessments stay inside the governed trace path.
- **Guardrail version baseline:** version 2 is the retention baseline. Version 1 was removed during the one-time lifecycle migration because its prior Terraform state did not yet include `skip_destroy`.
- **IaC:** Terraform owns AWS resources. The one provider gap—AgentCore resource policies—is reconciled by `terraform_data` using the documented control-plane CLI command.
- **Frontend:** the dependency-free open-beta page contains the coverage map, retention notice, feedback contact, disclaimers, and accessible chat.
- **Spend boundary:** the OpenAI project alert is a soft warning, while WAF limits, bounded turns/tool calls, and proxy concurrency cap exposure. AWS Budgets does not cap charges billed directly by OpenAI.
