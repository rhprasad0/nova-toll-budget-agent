## November 15: upgrade soupsieve, refreeze corpus 5.2.20

Dependabot #749 moved soupsieve from 2.9.2 to **4.0**. It arrives through
beautifulsoup4 and markdownify, which strands-agents-tools needs. Of the release
packages, only the timed-check package contains it, so only that one was
rebuilt. The agent, loader, publisher and chat-proxy packages rebuilt
byte-identical.

`uv.lock` is a protected eval source, so all three splits were refrozen as corpus
**5.2.20**. Cases, prompt points and fixtures are byte-identical to 5.2.19. Claude
recorded input approval at Ryan's request, and no one inspected the cases.

| Shadow | **10/10** valid | $0.014874 |

Total spend was **$0.126806** against a $2 cap, with complete usage.

Limitation: the harness 2.5.19 calibration predates the October 16, October 24
and November 15 dependency sets and the October 18 evaluator sources. Paid
application runs need a new combined calibration. No baseline was run.

Decision: **merge the upgrade and keep deferring the calibration.**

## November 15: upgrade Pillow and ADOT for security advisories, refreeze corpus 5.2.21

Open Dependabot alerts on `v2/` were all real: Pillow 12.3.0 (86 alerts, 10
critical) and OpenTelemetry 1.44.0 (5 medium). Pillow moved to **13.0.0**, which
needs strands-agents-tools **0.9.0**. ADOT moved from 0.19.0 to **0.22.0**, bringing
OpenTelemetry **1.45.1**. GHSA-mf5v-w3w3-f6cg needs OpenTelemetry 1.45.2, which no
ADOT release allows yet, so those two alerts stay open. Our code never imports
Pillow; it arrives through the evaluation tools and ships in the timed-check
package.

ADOT 0.22.0 renames one span processor and adds `AttributeRedactingSpanProcessor`,
which never exports and only replaces attribute values named by
`AWS_REDACT_SPAN_ATTRIBUTES`. The telemetry redaction boundary failed closed on the
new layout until it was added to the non-exporting processors. The real-startup
test confirms every exporter is still wrapped. The agent and timed-check packages
were rebuilt.

All three splits were refrozen as corpus **5.2.21**. Inputs are byte-identical to
5.2.20. Claude recorded input approval at Ryan's request, and no one inspected the
cases.
