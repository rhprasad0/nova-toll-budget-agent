TollChat privacy notice
Effective August 25, 2026

Who operates TollChat

Benevolent Clankers LLC operates TollChat. Send privacy questions or requests to contact@tollchat.ai.

What TollChat receives

TollChat receives the text you submit, which may include trip locations, travel times, commute schedules, and salary figures. It also receives the responses and tool results needed to answer you.

TollChat does not create user accounts. A random credential in a secure, HTTP-only browser cookie keeps public follow-up messages together for up to one hour. TollChat stores only a one-way hash of that credential with the temporary server session. It keeps the active conversation in the ephemeral microVM's memory. Starting a new chat removes the active conversation from TollChat's server memory. Server state disappears when the microVM stops or the server starts a new daily session. TollChat does not intentionally write conversations or the session credential to disk or attach the credential to traces or logs. Starting a new chat does not change OpenAI's retention described below.

Do not submit names, exact home or work addresses, account numbers, payment information, credentials, or other personal or confidential information.

Usage statistics

TollChat keeps two cumulative usage counters on AWS: counted anonymous chat sessions that sent a valid first message, and fully completed responses. A blocked response counts as completed. Errors, incomplete responses, and private preview traffic do not count. Collection starts with this release; earlier traffic is not backfilled.

When a public session starts, the temporary session record contains a one-way hash of a random browser credential, a random runtime ID, creation and activity timestamps, a one-hour expiration timestamp, a request lease, a usage-excluded boolean, and the random request IDs of responses already counted. These fields prevent duplicate counting. TollChat stops accepting the record after one hour, and DynamoDB then deletes it asynchronously. The record does not contain chat text, trip details, salary figures, IP addresses, or advertising identifiers.

One permanent aggregate record contains only the two cumulative counts, the collection start time, and the latest update time. TollChat retains that aggregate while the service operates. Once daily, TollChat publishes the counts, collection start date, and publication time as a static JSON file and displays them on the site. Exact daily totals let readers calculate the change since the previous day.

These counters measure sessions, not unique or verified people. Starting a new chat, using another browser, or returning after a session expires can count again. Failed requests, browser opt-outs, and automated traffic can also make the totals differ from the number of people who tried TollChat. TollChat does not sell this data or use it for targeted advertising. No third-party analytics provider receives these counters.

Route report access and agent measurement

When a browser, crawler, or agent requests a public toll route report under /tolls/, AWS WAF temporarily processes the IP address, request time, method, host and route path, user-agent, referring site, WAF action, and bot-classification labels. Before sampled requests or full logs are stored, AWS WAF substitutes cookie values, authorization headers, query strings, and full referrer values. Referring assistant families are represented only by non-identifying labels.

TollChat keeps filtered raw route-report access logs and Athena query results for seven days. Raw logs can contain an IP address and full user-agent. They do not contain chat prompts, responses, account identifiers, cookie values, authorization values, query strings, or full referrer URLs. Requests to /api/ and unrelated site pages are excluded from this route-report logging pipeline. Access is restricted to operators and AWS services used to produce the measurement.

TollChat keeps anonymous daily route aggregates while the service operates. They contain the UTC date, route, HTML or JSON representation, published generation age, agent category and confidence, WAF action, and request count. They do not contain IP addresses, full user-agents, referrer URLs, cookies, query strings, or user identifiers. Because CloudFront can cache reports for five minutes, published generation age has up to five minutes of uncertainty and does not prove the exact object version served.

These figures describe requests, not unique people, successful answers, citations, or confirmed origin responses. AWS WAF logging and metrics are best-effort and can be incomplete. The browser opt-out below controls anonymous chat usage counters; it does not disable access or security logging for public route reports.

Browser opt-out

To exclude a browser across tollchat.ai and www.tollchat.ai, open its developer console on either site and run:

document.cookie = "tollchat_usage_optout=1; Domain=tollchat.ai; Path=/; Max-Age=31536000; Secure; SameSite=Strict";

Then start a new chat. The one-bit preference cookie is not an identifier and expires after at most one year. It affects new sessions in that browser; it cannot remove an earlier count. To count future new sessions again, run:

document.cookie = "tollchat_usage_optout=; Domain=tollchat.ai; Path=/; Max-Age=0; Secure; SameSite=Strict";

Then start a new chat. Clearing browser cookies can also remove the preference.

Service providers

OpenAI receives prompts, conversation context, and responses to provide the AI portion of TollChat. TollChat sends the active conversation context on each request with Responses storage disabled (`store=false`); it does not use OpenAI's stored response state to continue a chat. OpenAI still keeps abuse-monitoring logs, which may include prompts, responses, and related metadata, for up to 30 days by default. OpenAI may keep those logs longer when required by law or needed to protect its services or others from harm. OpenAI states that API data is not used to train its models unless the API customer opts in.

We accepted OpenAI's standard abuse monitoring as a tradeoff to keep TollChat free to use. See https://developers.openai.com/api/docs/guides/your-data.

The map loads styles and tiles directly from OpenFreeMap. OpenFreeMap states that it keeps anonymized request logs without IP addresses and may temporarily record IP addresses for up to 30 days during a security incident. See https://openfreemap.org/privacy/.

Links to toll operators, VDOT, GitHub, OpenAI, and other sites are governed by those sites' privacy policies when you visit them.

Requests and changes

TollChat has no accounts or stable user identity, so it may not be able to locate records associated with a particular visitor. Send privacy questions or requests to contact@tollchat.ai.

This notice may change as TollChat changes. The effective date above will be updated when it does.
