TollChat

Ask what a supported trip costs now or how a tolled commute could affect your annual take-home pay. TollChat uses reasonable tax and vehicle-cost assumptions to give you a rough take-home-pay estimate.*

TollChat counts anonymous chat sessions that send a message and completed responses. It does not write conversations to disk or use those counters to identify people. It sends prompts, prior conversation context, and responses to OpenAI with Responses storage disabled. OpenAI still keeps abuse-monitoring logs, which may include that content, for up to 30 days by default. We accepted that tradeoff to keep TollChat free to use. Read how OpenAI handles API data and our privacy notice.

The code is open source. TollChat cannot see client-side failures, so send bug reports to contact@tollchat.ai.

We observed no fabricated costs in our 1,000-answer test. Toll and take-home-pay figures come from code, not AI arithmetic. 996 responses (99.6%) used only supplied numbers. One misstated a time. See the test limits.
