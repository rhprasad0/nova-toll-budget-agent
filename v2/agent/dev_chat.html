Ask for a current supported toll or see what a tolled commute could do to your annual take-home pay. Prices stay tied to TollChat’s constrained route and pricing tools—because a confident guess is still a guess. 👋

TollChat does not collect browser traces or analytics in this v2 preview, and conversations are not written to disk. Requests are processed by OpenAI and session state remains in server memory until reset or restart.

The code is open source. Because TollChat cannot observe client-side failures, please send bug reports to contact@tollchat.ai.
